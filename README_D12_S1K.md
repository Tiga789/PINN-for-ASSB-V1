# D12-S1K two-candidate 23-profile confirmation wrapper

## Purpose

D12-S1K is a confirmation-only wrapper stage. It does not train a new model and does not modify the D9.6/D9.5.1 GV1 mainline.

It validates exactly two D12-S1J-promoted candidates on a wider source prediction set, normally non-battery-8 23-profile 40ks first, then optionally 23-profile 200ks:

1. `d12s1k_low_only_revert_nonlow_to_baseline`
2. `d12s1k_low_plus_transition_fade_to_baseline`

Both candidates require an existing source run root containing paired predictions for:

- `baseline_d951`
- `d12s1e_p2d_low_anchor_soft`

The source run root should be generated by D12-S1E for the same profile/time-window scope.

## Recommended path
