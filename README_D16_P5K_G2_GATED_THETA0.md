# D16-P5K-G2 gated theta0 adapter audit

This package is a **fast no-training diagnostic**.

It does not read 50+ GB soft-label arrays. It reuses the by-profile exact metrics generated by P5K-G1:

```text
E:\XJTU battery dataset\_gv1_cache\xjtu_d16_p5kg1_MINI_EVIDENCE\D16_P5KG1_OBSERVED_THETA0_BY_PROFILE.csv
```

or, if not found:

```text
E:\XJTU battery dataset\_gv1_cache\xjtu_d16_p5kg1_observed_theta0_audit\D16_P5KG1_OBSERVED_THETA0_BY_PROFILE.csv
```

It tests gated combinations:

- default P5K-C baseline
- observed metadata gates + deployability-probe `G1-rule_v1`
- observed metadata gates + diagnostic ridge/oracle repairs
- split/hard-profile/oracle-shift diagnostic upper-bound gates

Important boundary:

- `theta0_oracle` uses soft-label initial internal states: diagnostic upper bound only.
- `ridge_*` uses oracle shift labels: diagnostic only unless a later protocol explicitly allows theta0 calibration labels.
- `G1-rule_v1` is the only pure observed-only theta0 correction from G1, but G2 only audits it; it is not automatically promotable.
