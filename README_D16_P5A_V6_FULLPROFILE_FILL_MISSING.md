# D16-P5A v6 full-profile fill-missing evaluator

Purpose: keep the 31 full-profile prediction files already generated by D16-P5A v4, and fill only the missing profiles using memory-safe chunked full-profile inference.

This package does **not** use sampled evaluation. It writes the missing cells into the same directory:

```text
E:/XJTU battery dataset/_gv1_cache/xjtu_d16_p5a_V4_D15_existing_on_ALL55/eval_full_profiles/predictions
```

It intentionally does not create duplicate `predictions_raw` or `predictions_projected` directories. The primary output is projected by default, matching the accepted D15-P3B inference-time theta projection policy.

## Smoke: fill only 1-2 missing cells

```powershell
cd "C:\Users\Tiga_QJW\Desktop\ASSB_Scheme_V1\PINN-for-ASSB-V1"

powershell -ExecutionPolicy Bypass -File scripts\gv1_run_d16_p5a_fill_missing_v6.ps1 `
  -LimitMissing 2 `
  -Device "cuda:0" `
  -BatchSize 32768 `
  -ChunkSize 200000
```

Then check:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\gv1_check_d16_p5a_v6_outputs.ps1
```

## Fill all missing profiles

```powershell
powershell -ExecutionPolicy Bypass -File scripts\gv1_run_d16_p5a_fill_missing_v6.ps1 `
  -Device "cuda:0" `
  -BatchSize 32768 `
  -ChunkSize 200000
```

If GPU or CPU memory is still tight, lower chunk size:

```powershell
-ChunkSize 100000
```

The final target is:

```text
prediction npz count: 55
FOUND: D16_P5A_V6_FINAL_SCORECARD.json
FOUND: eval_full_profiles/D16_P5A_METRICS_BY_PROFILE.csv
```

## Important notes

- Requires D15-compatible checkpoint:
  `E:/XJTU battery dataset/_gv1_cache/xjtu_d15_p2_rg_precision_benchmark/model/best_with_state.pt`
- This script ignores old D14/D12 `best.pt` files.
- Existing prediction files are not overwritten.
- Metrics are computed streaming/chunked for generated profiles, and one-file-at-a-time for existing profiles.
