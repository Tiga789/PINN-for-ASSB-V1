D14-P4 XJTU P2Dlite Soft-label Generator Smoke Package
=========================================================

Purpose:
  Implement a small-sample XJTU P2Dlite soft-label generator smoke.
  The key design requirement is that all physical prior parameters are stored
  in one standalone user-editable file:
      configs/P2Dlite_prior_xjtu_lr18650la_v0.json

  Both the soft-label generator and future model prediction/training code should
  read this same prior file, instead of duplicating battery parameters in
  multiple scripts.

Scope:
  - XJTU replay-profile NPZ input only
  - low-r P2Dlite model-consistent soft labels
  - n_r default = 17
  - output under E:/XJTU battery dataset/_gv1_cache
  - no training
  - no GV1 mainline modification
  - no SOH generation in the voltage soft-label generator
  - no full-P2D ground-truth claim
